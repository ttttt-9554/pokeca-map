ポケカ発見マップ v0.1

この試作版はSafariなどのブラウザで動作します。
index.html, style.css, app.js, manifest.webmanifest を同じフォルダに置いてください。
HTTPS対応の静的サイトホスティング（GitHub Pagesなど）にアップロードして利用します。
SafariでURLを開き、共有 > ホーム画面に追加、でホーム画面から起動できます。

注意：
- データはブラウザのlocalStorageに保存されます。ブラウザのデータを消すと消失します。定期的にJSONを書き出してください。
- グループ共有・ログイン・クラウド同期は未実装です。
- 地図タイルはOpenStreetMap提供のものです。インターネット接続が必要です。
- サンプルの初期地図中心は宇都宮ですが、位置情報の利用を許可すれば現在地へ移動できます。
- 試作段階であり、店舗名と緯度経度の一致は利用者が確認してください。
