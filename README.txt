ポケカ発見マップ v0.5 — 栃木県オフライン店舗検索
更新するファイル: index.html / app.js / style.css（GitHubリポジトリ直下）
manifest.webmanifest は更新不要。
検索時の外部店舗APIへの通信を削除しました。
重要：実在店舗の一覧は同梱していません。取得元を検証できないため架空の店舗データを入れていません。
店舗CSVの見出し: name,city,lat,lng
正確な店舗名と座標を入力してインポートしてください。
手動で店舗位置を長押し→店舗名入力→「店舗一覧に保存」でも登録できます。
以前の発見履歴からも店舗候補を作ります。
店舗データはlocalStorageに保存され、別の端末とは共有されません。
OpenStreetMap地図タイルの読み込みにはネット接続が必要です。オフラインなのは店舗名検索のみです。
