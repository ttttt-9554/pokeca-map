# 店舗住所の自動補完

既存の `lottery-store-sync` が15分ごとに店舗名の取込後、住所未登録の有効な店舗を確認する。
WonderGOO・Ganryu は公式トレカ店舗一覧、新星堂は該当都道府県の公式店舗一覧と照合する。
個別に確認した店舗は `verified-addresses.mjs` に出典と住所を保持する。

店舗名の全角半角・大小文字・空白・区切り記号を整えた完全一致と、都道府県の一致が必要。
略称や似た店名から推測しない。別名を追加する場合は同一支店であることを公式情報で確認する。
個別確認済みの住所を優先し、公式一覧内で同名同県の住所が食い違う場合は補完しない。
住所が特定できない店舗やオンライン応募先は空欄を維持する。

`lottery_store_address_pending_v1` と `lottery_store_address_fill_v1` は service_role 専用。
取得対象は店舗名・都道府県のみで、応募者やアカウント情報は扱わない。
保存時にも店舗名・都道府県の完全一致、有効な未統合店舗、住所空欄を確認する。
既存住所・手動修正・店舗統合は変更せず、住所と公式出典・更新日時のみ保存する。
住所の管理画面編集と、統合先住所を参照する既存のMAP表示は従来どおり利用できる。

公式サイトへ送信するURLは固定の店舗一覧のみ。店舗名を外部検索へ送信しない。
リダイレクト禁止、5秒タイムアウト、350KB上限、最大4並列で取得する。
失敗した一覧は他の一覧を妨げず、次の定期処理で再試行する。既知の対象がなければ外部取得しない。
公開カタログが両方停止していても、登録済み店舗の住所補完は試行する。
同期のJSON応答とログの `addresses` で、対象件数・一致・保存・未解決・取得エラーを確認できる。

検証: `node scripts/test_store_address_sync.mjs`
